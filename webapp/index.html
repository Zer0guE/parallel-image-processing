Parallel Image Processing


The same filter on the same images: first on one core, then on many. Press one button and compare.


How this program works
  1. The job. Every image gets the same three steps: grayscale, Gaussian blur, then Sobel edge detection. The result is saved as a PNG.
  2. Sequential. One process handles the images one after another on a single core. Its total time is Ts.
  3. Parallel. A pool of worker processes shares the images. Each worker is its own program on its own core. Its total time is Tp.
  4. The comparison. Speedup = Ts / Tp. Efficiency = speedup / workers (1.00 is perfect). Images per second shows how much work gets done each second. The two runs go one after the other, never together, so they do not compete for the CPU.
  5. The check. When both finish, every parallel output image is compared pixel by pixel with the sequential one.
What to run

Press the button. Sequential runs first, then parallel.
